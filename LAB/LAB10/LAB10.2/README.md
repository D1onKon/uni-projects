\# XOR File Encryption in C



A simple C program that performs basic file encryption and decryption using the XOR (^) operation with a user-defined key character.



\---



\## Features



\- Reads an input text file

\- Encrypts data using XOR cipher

\- Saves encrypted output to a new file

\- Uses a single key character

\- Works for both encryption and decryption (same program)

\- Basic file handling in C



\---



\## Technologies



\- C Programming Language

\- Standard C Library (`stdio.h`)
