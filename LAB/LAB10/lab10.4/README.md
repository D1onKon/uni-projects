\# Student Grade Averages from a File in C



A simple C program that reads student grades from a text file and calculates the average score for each course.



\---



\## Features



\- Reads student grades from a file

\- Supports multiple students and 3 courses per student

\- Calculates the average grade per course

\- Basic file handling in C



\---



\## Technologies



\- C Programming Language

\- Standard C Library (`stdio.h`)



\---



\## Input File



The program reads from:



```txt

students.txt

```



Each line contains 3 grades (one per course) for a single student:



```

5 3.5 9

9 6 4.5

```



\---



\## Output



The program displays the average grade for each course:



```

7.00 4.75 6.75

```



\---



\## How to Run



1\. Open `lab10.4.c` in VSCode

2\. Make sure `students.txt` exists in the same folder

3\. Press `F5` to build and run
