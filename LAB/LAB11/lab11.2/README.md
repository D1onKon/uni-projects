\# 🔁 Reverse String Program



\## 📌 Description

This program reads a string of up to \*\*100 characters\*\* from the user and displays the string in \*\*reverse order\*\*, starting from the last character and ending with the first.



\---



\# 🧠 Problem Statement



Write a program that reads a string containing up to 100 characters and displays its characters in reverse order, from the end towards the beginning.



\---



\# ▶️ Example



\## Input

```text

HelloWorld

```



\## Output

```text

dlroWolleH

```



\---



\# ▶️ Another Example



\## Input

```text

Programming123

```



\## Output

```text

321gnimmargorP

```



\---



\# ⚙️ Algorithm



1\. Start the program

2\. Read a string from the user

3\. Calculate the length of the string

4\. Traverse the string from the last character to the first

5\. Display each character in reverse order

6\. End the program



\---



\# 🛠️ Key Concepts Used



\- Strings / Character Arrays

\- Reverse Traversal

\- Character Access Using Indexes

\# 📝 Notes



\- Maximum input length: \*\*100 characters\*\*

\- Spaces, numbers, and symbols are also reversed

\- The original string remains unchanged
