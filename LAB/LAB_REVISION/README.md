\# C Programming Exercises – Revision Set



This repository contains a collection of C programming exercises focused on fundamental concepts such as arrays, pointers, functions, recursion, structures, and file handling. The exercises were completed as part of revision practice for improving programming skills and exam preparation.



\---



\## 📚 Topics Covered



The exercises in this set include:



\- Arrays and pointer arithmetic

\- String manipulation (`gets`, `fgets`, `strcpy`, `strcat`)

\- Functions and recursion

\- Structures (`struct`)

\- File handling (`fopen`, `fclose`, `fprintf`, `fscanf`)

\- Searching and basic algorithms (sum, min/max)

\- Dynamic input handling and loops



\---



\## 🧠 Skills Practiced



\- Working with pointers and memory access

\- Reading and writing files in C

\- Using structs to organize data

\- Implementing recursive functions

\- Processing user input safely

\- Debugging common C programming errors



\---



\## 📁 Structure



Each file in this repository corresponds to a separate exercise and focuses on a specific concept or combination of concepts.



Example topics:

\- Sum of array elements using pointers

\- String concatenation using `strcat`

\- Recursive sum from 1 to N

\- Structure-based product filtering

\- File input/output operations

\- Finding max/min values in datasets



\---



\## ⚠️ Notes



\- Some exercises use `gets()` for educational purposes, but it is \*\*deprecated and unsafe\*\*. In modern C programming, `fgets()` is preferred.

\- The code is written for learning and revision purposes, not production use.

\- All file operations assume valid input format unless otherwise specified.
